## [0.2.1] - 2026-11-20

### Fixed
- Month view: after typing a date, the first press on ‹ › (or on a «Copy» button) was lost, because leaving the field redrew the page between mouse down and up; the page is now redrawn only when the date really changed.

### Changed
- fff-kit 1.8.1: when the browser blocks or lacks storage (`localStorage`/`sessionStorage` throw or are missing), the page now starts with temporary in-memory storage instead of stopping; data is not kept after the page is closed.
- fff-kit 1.8.1: the guide that enlarges small controls to 44 px now also measures the width of the page body and of the parent, so a row of buttons can no longer run off the screen (the group is left untouched when enlarging would make it too wide).

## [0.2.0] - 2026-11-17

### Added
- A working converter between eleven calendars (Gregorian, Julian, Revised Julian, Hebrew, Hijri tabular, Persian, Coptic, Ethiopian, Chinese lunisolar, Maya, Mars Sol Date), one tested plugin each.
- Month view with a second calendar, Romanian old/new style notes, Western and Orthodox Easter, Chinese solar terms and New Year, and an atlas built from `data/calendars/`.
- Interface in eight languages (with each language’s date order), dark and light themes, keyboard and screen-reader support, mobile layout.
- Tests: `node --test` for plugins, engine, data and translations; browser tests in the hub (all languages, accessibility, hostile inputs, out-of-range dates).
- `src/`, `plugins/` and `scripts/build.mjs`: the single `index.html` is now built from sources, and `--check` verifies it.
- ISSUES_GOOD_FIRST and CODE_OF_CONDUCT translated into all eight languages.
- README in English, Romanian, French, Italian, Spanish, Portuguese, German and Hungarian: status and planned scope sections (derived from `ISSUES_GOOD_FIRST.md`).
- Installable (PWA): `manifest.webmanifest`, `sw.js` and icons generated by the shared kit (`fff-kit/pwa`); the page works offline after the first visit over HTTPS.

### Changed
- `data/calendars/example.json` now describes the French Republican calendar (no plugin yet) as the template for contributors.
- The workflow runs on Ubuntu 26.04 with Node.js 26 and also runs the tests and the build check.
